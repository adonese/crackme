# pwn.college Reverse Engineering

This is the best pwn.college entry point for this repo.

## Sections

| Folder pattern | Topic |
| --- | --- |
| `level-1-*`, `level-2-*`, `bit-bender`, `substitution-sorcery` | License-key style crackmes and input mangling. |
| `level-6-*`, `level-8-*` | Harder mangling. |
| `level-9-*`, `level-10-*`, `level-11-*` | Runtime patching. |
| `level-15-*` and later Yan85 levels | VM and custom architecture reversing. |
| named folders such as `hashing-heifers/`, `salty-stampede/`, `predictable-migration/` | Standalone RE exercises with generated variants. |

Each level usually has many `_0` through `_15` variants. Start with `_0` and
only branch out when you want another version of the same concept.
