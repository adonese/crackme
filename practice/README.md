# Practice Material

This directory keeps a broad local practice library. The size is intentional:
more material is useful as long as the repo gives you a map instead of a dump.

Start with:

- `../docs/MAP.md` - shortest map of the whole repo.
- `INDEX.md` - practical route through the material.
- `ROUTES.md` - focused playlists by mood/topic.
- `CURATION.md` - how to think about the different quality/depth tiers.
- `crackmes/crackmes-one/MANIFEST.md` - downloaded crackmes.one archive sources.

## Local Mirrors

- `crackmes/` - extra classic crackmes, currently from crackmes.one.
- `ctf/` - CTF-style bundles with handouts, source, and spoiler material.
- `courses/` - larger course mirrors and module metadata.
- `courses/pwncollege-program-security-dojo/` - full public pwn.college
  Program Security Dojo repository mirror.
- `courses/pwncollege/reverse-engineering-module.yml` - quick copy of the
  pwn.college Reverse Engineering module metadata.
- `courses/nightmare/` - full Nightmare binary exploitation / reverse
  engineering course mirror.

## Hosted Platforms

These are intentionally kept as links because the platforms serve challenges through
their own web accounts or in-browser environments rather than one stable public bundle.

- picoGym: https://picoctf.com/get_started.html
- Microcorruption: https://microcorruption.com/
- FreeHackQuest reverse puzzles: https://freehackquest.com/quests/reverse
- CS.RIN.RU: https://cs.rin.ru/forum/
  The forum requires an account for normal access and is not mirrored here.
  Use it only for legal learning discussions, tooling notes, and public references;
  skip game files, cracks, DRM bypasses, and redistribution threads.

## Suggested Order

1. Work through `crackmes/` and the existing `solutions/` only after attempting each one.
2. Try `crackmes/crackmes-one/extracted/iseey0u-crackme1-2026-05-10/`.
3. Move into `ctf/crackmes-one-ctf-2026/wallpaper/`.
4. Continue with pwn.college Reverse Engineering easy levels.
5. Use Nightmare's `Intro to Tooling` and `Beginner RE` sections.
